# 整體視覺方案｜從這裡開始

本手冊一律使用 Claude App，不需要選擇 AI 工具，也不需要先會寫程式。你負責準備資料、看預覽與給回饋，AI 負責製作與整理。

## 設計師請看

先開啟 [教學入口](index.html)，選擇閱讀方式：

- [使用須知](guide-tools.html)：圖文了解 Skill 分工、五個確認點、工具與常見問題。
- [完整流程](使用教學.html)：按順序了解各階段的操作與確認。
- [依情境](快速索引.html)：從目前已有成果找到準備資料與開始指令。

兩種方式都在同一份教學專案內，可隨時切換。另有 [layout 第一次製作完整流程文字版](使用教學.md)與 [情境文字版](快速索引.md)。

四頁統一載入 `css/manual.css`，教學指令的一鍵複製使用 `js/copy-code.js`，右下回到頂部使用 `js/scroll-top.js`。調整共用外觀時修改這份 CSS；複製或分享教學時，請一併保留 `css/` 與 `js/` 資料夾。

手冊涵蓋資料準備、App 操作、產圖、視覺與動態確認、完整網站、客戶校稿，以及 EVO 轉換、後台匯入與驗證。已有設計稿只需切版時，使用獨立 Lin-EVO 教學。

桌機完成並經內部確認後，直接接續 RWD，完整檢查後再交客戶校稿；各情境的啟動指令已包含這項範圍，不需另選 RWD 情境。Webtech2 已完成首頁時，由 Lin-EVO 依新規範重切視覺相同的靜態網站，再延伸內頁。

Skill 由維護者事先在 Claude 網頁版統一設定與更新，設計師使用已完成設定的帳號或團隊空間，直接照教學貼指令，不需自行下載或安裝。

## 維護人員請看

安裝與更新方式見 [INSTALL.md](INSTALL.md)，AI 工作規範見 [主 Skill](skills/visual-solution-immersive-director/SKILL.md)。

套件包含整體視覺主 Skill、8 支 GSAP 技術 Skills、Eagle 相關 Skills，以及手冊明列的歐群生醫、毅嘉科技視覺提案／動態分鏡示範與必要素材；不含其他客戶案件、案例資料庫或憑證。工程師提供的範本資料需另行取得。

歐群生醫與毅嘉科技案例連結放在手冊第 4、5 步，預覽圖分別放在 `examples/ocean-medi/`、`examples/ichia/`，原示範頁與所需資源在 `Ocean-Medi-歐群生醫/`、`Ichia-毅嘉科技/`。案例用於理解提案展示與確認方式，不構成其他案件的設計規則。

教學更新不代表已完成實際案件製作或客戶確認。

## 已設定的工作規範

設計師直接使用 Visual-Solution-Workflow、Lin-EVO 與 Miffy-EVO。設定、版本更新與必要技術規範由維護者統一處理；缺少項目時聯絡維護者，不要求設計師取得 Skill 包。

Lin／Miffy 依各自來源資料夾維護；本機 Lin 在 `skills/lin-skill/Lin-EVO`，Miffy 在 `skills/Miffy-EVO`，不再假設共用同一個 Git 來源。工程師 HTML 套件由人工更新；既有 JSON 案件沿用原流程。維護打包方式保留在 [INSTALL.md](INSTALL.md)，不屬於設計師操作步驟。

[情境 4｜靜態頁面轉 EVO](快速索引.html#case-7) 整合轉換打包、後台預檢與匯入、編輯儲存與發布後前台驗證。匯入與發布須指定目標及授權，缺後台工具時由設計師操作並回傳結果。

分享教學時保留頁面、CSS、JavaScript 與案例素材即可；教學不要求附上 Skill 安裝包。

轉換接續見 [靜態頁面轉 EVO](快速索引.html#case-7)。詳細條文由獨立 Lin-EVO／Miffy-EVO 維護。
