## T02｜環境、檔案與 Git

- 先盤點實際 HTML、SCSS、JS、匯入、編譯、預覽與 Git 狀態；保留未提交修改。沿用既有基底、套件版本、匯入語法與工程入口，不強制改 @import 為 @use。
- Common 只有一份有效來源，不造第二份 _common.source.scss。空檔不代表缺檔或完成；保留有用途的空資料夾及 .gitkeep。確認實際編譯出非空 CSS 且頁面載入再作視覺確認，不手改編譯產物。
- 首頁與各內頁需有實際可瀏覽入口，草稿不算整案完成。工程位置依本案檔案管理，不強迫移到 06-切版。文件、程式與圖片各用必要格式，不限制可觀看的提案產物只能用 MD。
- 新基底須記來源版本，不覆蓋既有案件、不回推來源庫；不擅自移除巢狀 Git。不把憑證寫入網址或文件，不索取明文 Token。安裝、Git 寫入、發布及部署依本次授權，不因切版規範自動執行；使用者要求推到公司 Git 時依 [Git 流程](git-workflow.md) 執行。
- 正常續作沿用有效環境，不反覆重裝；異常先定位。編譯與預覽由同一任務執行，不依賴外部角色交接。

## T15｜新增共用項目與修改後檢查

- 修改前找出共用元件、Common、JS 入口及使用頁面；先判斷影響，不只驗證眼前頁。
- 共用修改檢查所有受影響頁面的載入及必要操作，並實看首頁與各受影響頁型的代表畫面；頁面專屬修改檢查該頁與跨頁路徑。
- 查 HTML、JS 動態 class 及 runtime 狀態再刪失效樣式；不能整批清除套件產物或其他元件的事件。
- 編譯／語法、瀏覽器功能、視覺與使用者確認分開記錄。預設 2560×1280 桌機，RWD 僅另行授權；未測的平台串接、裝置與功能如實標明。
