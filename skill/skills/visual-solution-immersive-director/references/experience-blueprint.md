# Experience Blueprint / PRD

Treat this as an experience blueprint, not a conventional feature-only PRD.

## Project-level sections

Include:
- objective and success intent,
- audience and primary user journey,
- selected creative premise,
- content hierarchy,
- page map,
- global navigation behavior,
- experience arc,
- motion principles,
- visual-system summary,
- technical architecture intent,
- 2560×1280 desktop strategy,
- performance constraints,
- content completeness requirements,
- experience-layer vs commerce/information-layer responsibilities,
- Signature Moment placement and rationale.

## Per-section specification

For each major homepage section define:
- purpose,
- required content,
- visual protagonist,
- viewport/composition role,
- entry state,
- scroll/camera progression,
- pinned/static/moving elements,
- readable information zone,
- transition to next scene,
- immersion intensity: low / medium / high,
- candidate implementation technique,
- 2560×1280 desktop intent,
- deferred RWD note when relevant,
- conversion/CTA role,
- acceptance note.

Do not specify pixel-perfect values prematurely. Keep typography sizes, exact spacing, and fine layout calibration for implementation/design tuning unless a value is necessary to protect behavior.

## Rhythm Map

Explicitly mark:
- opening/hero,
- build-up,
- first wow moment,
- reading/rest section,
- secondary peak,
- conversion/CTA zone,
- closing state.

Avoid continuous maximum intensity.
