# Reference Research and DNA Extraction

In CREATE, references sharpen the selected direction. In RECREATE, audit the approved reference as the target; record what must be preserved instead of applying the transformation rule. Hybrid work follows the explicitly selected feature constraints.

## Evidence

Open relevant pages and operate their scroll and interactions when available. Record URL, viewport, observed states and unavailable evidence. Screenshots prove composition, not motion or library choice. Label technical guesses as inference; never claim a site uses Three.js or a particular animation engine from appearance alone.

## Source Priority

1. User-provided references
2. Eagle private library (required when usable user-provided references are absent; use MCP/API or authorized screen control)
3. Awwwards
4. Aura
5. GSAP showcases and demos
6. Three.js/WebGL showcases
7. Codrops and creative-development references
8. Strong studios and relevant cross-industry references

Use current research when examples or technologies may have changed.

## Reference DNA

For each selected reference extract only relevant dimensions:
- Visual DNA
- Motion DNA
- Interaction DNA
- Layout DNA
- Typography DNA
- UI DNA
- Spatial DNA
- Narrative DNA
- Camera Language
- Scroll Behavior
- WebGL Technique
- Lighting
- Atmosphere
- Transition

Then answer:
- **What to take** — principle or behavior worth studying
- **What not to take** — visual identity, branded element, or implementation pattern that should not be copied
- **Why it fits** — link to client/business/experience need
- **How to transform** — how to reinterpret it into the client's own system

## 設計方向前的參考關卡（二擇一）

提出設計方向供確認前，必須完成以下任一路徑：

1. **使用者提供參考**：實際開啟並分析提供的網站、截圖或影片，記錄來源、已查看範圍、要參考的特徵及本案適用理由。只收到連結、無法讀取內容或只看名稱，不算完成。有足夠可分析內容時不強制連接 Eagle；截圖只能證明靜態構圖，未看動態須明列。
2. **Eagle 查找參考**：使用者未提供可用參考時，必須依下節確認 Eagle 可用，實際搜尋、查看並分析相關案例，不能只驗證連線就交付設計方向。

兩條路徑都沒有可分析內容時，先請使用者提供可讀取的參考，或完成 Eagle 連線與授權；資料整理仍可繼續，但不將設計方向標成可確認或已確認。參考分析完成後，結合本案品牌與需求提出方向，說明參考用途及邊界，再由使用者確認。看過參考不代表方向通過，也不自動授權忠實重建。

## Eagle 可用性檢查（採 Eagle 路徑時）

選用 Eagle 路徑時，先讀同套件的 [Eagle 工具規則](../../eagle/SKILL.md)，再依實際能力選擇管道：

1. **Eagle MCP／API**：優先使用已連接的專用工具，依工具文件唯讀確認資料庫、搜尋相關項目並查看內容。使用本套件 CLI 時須符合其應用程式及連線前提。
2. **直接控制螢幕**：當前環境提供桌面操作工具且使用者已授權時，可直接操作 Eagle 的視窗、搜尋欄、資料夾、標籤及項目預覽。先確認目標視窗與資料庫，再依當下可見畫面操作；每次操作後核對結果，不盲點、不擅自操作其他應用程式或無關內容。此管道不以 Eagle MCP 已啟用為必要條件。

至少一種管道必須實測通過：確認本案指定資料庫、完成一次相關搜尋，並開啟一個實際項目查看內容，記錄使用管道、資料庫、搜尋條件及項目名稱／ID／來源網址等可取得的識別。零筆結果不等於工具失效；可改以庫內已知項目驗證開啟能力，另外記錄沒有合適案例的缺口。不為補足參考數量硬選無關案例；確認工具可用但無合適案例時，才由其他來源補足。

兩種管道都不可用、權限被拒或目標庫無法確認時，列明需使用者或維護者完成的開啟 Eagle、連接工具、選定資料庫或系統授權步驟；完成後重新驗證。也可改由使用者提供可讀取的網站、截圖或影片，實際分析後走「使用者提供參考」路徑，不再強制驗證 Eagle。兩條路徑都未完成時停止設計方向的推進。不擅自安裝程式、改系統權限、繞過拒絕或以其他管道規避相同存取限制。

Claude App／網頁版載入 Skill 不代表已有桌面控制或本機存取能力；只有當次實際提供的工具才能操作。設定由維護者或使用者完成，不宣稱寫入本規則就已啟用工具。換環境、斷線或操作失敗時須重驗；同一工作階段已有成功證據且連線未變，不重複要求授權。

搜尋與預覽不包含改名、移動、增刪收藏、標籤或資料夾，也不自動授權切換到其他資料庫；需要整理收藏時另依 eagle-visual-solution-curator 提案並取得核准。查找設計參考的螢幕操作授權不延伸成操作 ChatGPT 產圖。

## Eagle Behavior

After the required access check, search with combinations of industry, tone, composition, motion type, scroll behavior, WebGL technique, UI/typography, material, color, lighting, and scene type. Use the verified MCP/API or screen-control route.

Prefer a small curated set over a large dump.

## Output

Produce a Reference DNA Matrix and a decision-oriented Moodboard/Reference Map. References must validate and sharpen a selected direction; they must not invent the direction after the fact.
