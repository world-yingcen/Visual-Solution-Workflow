# 整體視覺的整頁完整度

用於核心片段擴展整頁、完整度改善與交付前檢查。依品牌和本案內容判斷，不把毛米勾勾的寵物、粉黃配色、照片堆疊或固定動態套到其他客戶。

## 先鎖內容，再整合畫面

沿用使用者已確認的區塊順序與用途（例如 A–E），把每段對應到實際 section、必要資訊及 CTA。整合重複內容時保留原任務；不可因動畫方便而刪段、重排或改寫已確認架構。缺規劃先查案件文件，找不到就明示未知，不自行替字母補定義。

核心片段驗證後，在既有 Blueprint 或進度檔補一張精簡整頁場景表：

| 區塊／目的 | 主次構圖與閱讀順序 | 素材／來源／缺口 | 動態強弱與理由、進入／閱讀／離開及相鄰交接 | 行動／驗收條件 |
|---|---|---|---|---|

涵蓋頁尾，不能用首兩屏的品質代表整頁。每段先明確要讓訪客知道、相信或採取什麼行動，再決定畫面。

這張表在擴展整頁前完成，不能等交付時才補。標示固定舞台與自然捲動區段、視覺強弱及閱讀停留；CTA 與 Footer 分別檢查構圖和邊界。安靜段可降低動態，但仍須有清楚層級，不能用無目的的大空白代替設計。

## 構圖與細節

- 每段有清楚視覺主角，文字、圖片、裝飾有大小與遠近關係。留白需支撐焦點或閱讀；大面積空洞先調整比例、對齊和內容密度，再決定是否補素材。
- 細節從品牌語言延伸：IP、圖像、標籤、線條、圖示與互動提示各有位置及作用。避免每段塞相同貼紙、英文眉標和編號。
- 閱讀順序保持簡單：主張、必要說明、行動。標題勿被強制斷成過多短行；已有使用者偏好的排法要保留。
- 按鈕的重要性要在構圖中看得出來。依該段目的設計文案、尺寸、對比、位置與 hover／focus 回饋；不要讓裝飾和標題壓過主要行動。

## 素材主動補齊，但來源不能混淆

- 正式 Logo、IP、產品包裝優先使用原檔；適合時拆層、去背、安排入場或點擊回應，保留辨識特徵。整張浮動不等於角色肢體動畫。
- 信任證據用真實活動、人物、產品使用或現場照片。生成情境可營造氣氛，不可充當真實顧客、好評或成效證據。
- 照片和引文可在同一區塊整合；未核實人物對應時不可設計成該人物的推薦語。來源與待確認事項記在校稿紀錄；正式頁面需要揭露時用清楚、適度的文字。
- 先盤點客供與案件素材，再補必要配圖。去背主體、對話氣泡或小互動應幫助理解內容，不能遮住商品、條件或 CTA。
- 滿版素材依容器及動畫最大位移規劃安全範圍。檢查頭、腳、商品與文字是否裁切、上下是否露底；單靠放大或 contain 不能解決時，處理來源圖、補背景或延伸構圖，再置入實看。生成編輯依可用工具規則執行，不改壞正式包裝、人物或 IP。

## 整頁動態節奏

全頁都要有動態編排。逐一設計每個主要區塊與交界的接續關係，依內容選擇以下強度，不設固定數量、比例或輪流套用順序：

| 強度 | 適用目的 | 編排方式 |
|---|---|---|
| 重點轉場 | 主題轉變、重要原理或品牌敘事推進 | 主圖延續、場景變化、遮罩等；動作完成後留下穩定閱讀時間 |
| 輕量銜接 | 將視線交給下一段、建立圖文閱讀順序 | 小幅進退、分層揭露或背景過渡；內容及 CTA 保持容易接近 |
| 安靜閱讀 | 長文、信任證據、聯絡資訊等需要專注的內容 | 內容穩定，以自然捲動、留白及前後段收放銜接；必要的操作回饋照常保留 |

- 由已確認的核心動態提取語言，延伸到適合的段落：揭露、展開、位移、遮罩、堆疊或場景交接。避免只完成 Banner 動態便把其餘段落全部留靜態；也不為湊動態而讓每段 pin、旋轉或放大。
- 每項效果須服務視線引導、內容理解或前後連續性。若移除效果後這些目的不受影響，且沒有明確品牌表現作用，應減弱或移除。安靜閱讀須依內容需要安排，不能當作後半頁未設計的理由。
- 強動態之間安排穩定閱讀與呼吸，避免連續搶焦點。相同語言可以延續，但幅度、時序和停留應隨內容調整；不把效果種類多寡當作品質。
- 分開安排跨區塊轉場、段內敘事及按鈕／角色回應；避免下面只剩相同 fade-up，也避免所有裝飾同時循環。
- 每個主要效果明確起始、過程、結束與反向狀態；文字在可閱讀的穩定狀態停留，動態不能讓瀏覽者誤以為卡住。
- 照片堆疊時保留主體、適當露出前張邊緣；文字不跟著多層疊壓。捲動距離配合照片數與閱讀時間，不製造無內容的等待。
- 沿用現有動畫與捲動系統，檢查 pin、重算、圖片載入及深連結重載；不藉新增第二套捲動引擎掩蓋問題。

## 優惠與信任的說服力

優惠區要讓人看懂「得到什麼、適用條件、下一步」。用已確認金額、商品及方案建立視覺重點；沒有優惠幅度、門檻或期限就記待確認，不虛構限時、倒數、評分、成交數或組合省額。單品折扣不能冒充多盒方案。

信任區選具辨識性的真實照片與具體內容，避免把大圖、引文、來源各放在彼此無關的遠處。照片不足時明示素材缺口，不以生成照片補成假實證。

## 指定尺寸與交付門檻

本 Skill 的預設桌機 viewport 是 2560×1280；以該尺寸完成本輪構圖、互動與整頁驗收，記錄瀏覽器、CSS viewport、縮放與測試日期。不要用 1920、1536 或較小預覽代替 2560×1280 通過。RWD 不在本階段，不設計、不修改、不驗收，也不宣稱已完成；既有響應式功能保留，避免為桌機修改而任意刪掉。若使用者明確指定另一個桌機尺寸，記錄取代原因與實際尺寸後依指示執行。

交付前從頂端走到頁尾，逐段看靜態構圖及前進／倒退轉場，實際點 CTA、篩選、角色與照片互動，檢查重新載入與深連結。檢查圖片邊界、文字層級、留白、資訊覆蓋、按鈕落點、資源錯誤及捲動卡住。以當前版本截圖或可重現操作記證據，修正後重驗受影響區塊與前後銜接。

以下任一未解就列缺陷，不能標完整首頁通過：必要內容缺漏、後半頁尚未設計、素材裁切或露底、閱讀被動畫阻礙、主要 CTA 不可辨識或無有效落點、真實證據與生成素材混淆、捲動卡住。安靜區塊和留白本身不是缺陷，需依其目的判斷。
