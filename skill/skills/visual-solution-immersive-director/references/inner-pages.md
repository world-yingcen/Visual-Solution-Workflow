# 整體視覺方案｜內頁設計與製作

用於已確認首頁後的內頁延伸；不新增角色或另開設計系統。只有流程文件修改或參考分析的授權時，不開始客戶頁面實作。沿用本案模式與已確認內容；若首頁未確認，列出哪些視覺約定可沿用、哪些仍待定，不把假設當定案。

## 1. 盤點頁型與功能邊界

先讀現行 PRD、網站架構、首頁視覺約定、進度及工程。將下列欄位補入既有頁面清單，不建立第二套需求正本：

| 頁面／路徑 | 使用目的與主要行動 | 頁型／共用版型 | 真實內容與素材來源 | 功能及平台支援狀態 | 待確認項目 |
|---|---|---|---|---|---|

依內容決定主題介紹、列表、詳情、下載或表單等頁型；頁面數不等於版型數。有新敘事或特殊功能才另設版型。不要因參考站有搜尋、分頁、詢問車而替本案加功能；資料量少時採較簡單的導覽。

區分現有元件、平台已支援、前端示範、待串接與未知能力。前台觀察不能證明 CMS 欄位、API 或後台功能可用；在實作相關功能前核對本案平台契約。未確認的能力標出缺口，不承諾可正式使用。

## 2. 功能參考與品牌延伸

公司案例只取使用者指定的結構與行為。需要案例對照時讀 [內頁功能參考](inner-page-references.md)，只重看與本輪頁型相關的頁面，不每次巡覽三站。參考網址不是程式碼來源，也不授權搬用其他客戶素材。

沿用首頁的色彩、字體、按鈕、圖片語言與品牌輔助圖形；補齊內頁標題／Banner、麵包屑、閱讀寬度、段落間距、分類、頁籤、表格與收尾 CTA 的共通規則。首頁主視覺不必原樣複製，每頁仍需清楚的內容焦點。品牌介紹可自由編排，系統列表／表單則遵守本案平台限制，不能把限制套在所有創意區塊上。

保留真實內容的資訊層級；不為套版任意刪減規格、改寫事實或補造數據。缺素材提出具體替代與待確認標記，Sample 和佔位內容不能當正式完成。

## 3. 核心頁以首頁完成度設計

關於我們、ESG、服務等承載品牌敘事與核心價值的頁面，按首頁等級的完整設計製作，不降級為一般圖文資訊頁。是否屬核心頁依本案任務判斷，不只看頁名。

- 為整頁建立主題、內容層級、專屬構圖與場景節奏；沿用品牌系統，但不複製首頁版面或替換文字了事。
- 規劃各主要區塊的進場、閱讀、退場及相鄰轉場；代表試做涵蓋相鄰區塊，不只展示首屏動畫。
- 依內容使用能幫助理解的互動，例如歷程推進、服務步驟、數據變化或圖文對照；只是可選方法，不是每頁必加清單。
- 動態分布到整頁有意義的位置，不能只做 Banner；重點段有表現、資訊段可安靜閱讀，不要求每段都強動態。
- 依主流程的整頁完整度及動態分鏡要求自查到收尾 CTA／Footer，不能因標為內頁就省略設計與互動確認。

文章列表、下載、一般文章、規格與表單等查閱／操作型頁面，則以資訊清楚與操作穩定為主。兩者按任務分流，不把所有內頁都做成沉浸式長篇。

## 4. 代表頁先行

提出最少但足以涵蓋差異的代表頁組合，不固定每案都做四種。每個代表頁先整理 2560×1280 構圖、內容順序、圖片裁切、互動狀態與下一步入口，使用本案真實長短文案及素材展示。

在已授權的製作範圍內完成代表頁預覽與自查，讓使用者確認版型及行為後再展開同類頁。已有明確版型確認或自主執行授權就沿用，不重開提案。新主視覺或複雜轉場按主流程先展示設計與動態，不把首頁核准當成新效果核准。

## 5. 有用途的動態與閱讀節奏

逐一考慮主要區塊的進入、閱讀、離開及相鄰交接，可採重點轉場、輕量銜接或安靜留白。不能只讓 Banner 有設計，也不能每段一律淡入、釘選或強制停留。

- 品牌敘事：動態用來連接圖像、概念或前後內容。
- 分類、頁籤與相簿：讓切換前後關係清楚，保留選取狀態與操作回饋。
- 文章、規格及表單：優先穩定閱讀、輸入與查找，不持續移動資料。
- 沿用既有動態技術，規劃減少動態時仍完整可讀、可操作的狀態。

## 6. 實作、驗收與交付

HTML／SCSS 命名、拆檔、Common、共用元件與初始化依 [切版工程規範](frontend-standards.md)，不得引用高效方案的動態上限來簡化核心頁。

共用 Header、Footer、按鈕及成熟元件，不為每頁另生一套 CSS／JS。依 [PRD 與檔案管理](project-files.md) 更新單一工作入口與頁面索引；沿用現有工程路徑，不因本階段自動搬移舊案檔案。

依 [主 Skill 的全站共用導覽與頁尾](../SKILL.md#全站共用導覽與頁尾) 執行：首頁與內頁 Nav／Footer 外觀一致、Nav 下滑後固定於視窗頂端、每頁視窗右下角都有 Scroll Top。內頁驗收須與首頁對照，不能只確認元件存在。

在實際 2560×1280 CSS viewport 檢查代表頁及展開頁面的內容、裁切、留白、CTA／Footer 接縫與動態。依頁型驗證：

- 列表 → 詳情 → 返回、麵包屑與跨頁 CTA；有篩選／分頁時確認狀態與結果。
- 頁籤及相簿切換、鍵盤操作與焦點；內容切換後不遮擋或留下失控空白。
- 長標題、多圖、少量內容及空資料情況；只測本案適用的狀態，不為測試新增功能。
- 下載目標、資源載入、console 與共用元件受影響的既有首頁。
- 表單必填、錯誤及結果回饋；沒有後端就明示示範／待串接，不顯示假的寄送成功。正式表單不為自查擅自送出。

分別記錄已實作、已實測、使用者確認及待串接。桌機交付不代表 RWD 完成；Tablet／Mobile 仍待使用者另行要求。交付提供有效預覽、改動檔案、測試範圍及少量需要判斷的項目，不只交文件。
