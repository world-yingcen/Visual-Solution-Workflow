# 共用切版規範｜獨立 LIN

共用規範唯一來源：[world-yingcen/lin-skill](https://github.com/world-yingcen/lin-skill)。本方案不再維護共用條文副本。

1. 依當前工具的 Skill 清單定位已安裝的 lin-frontend，完整讀取其 SKILL.md。
2. 按 LIN「每次使用」流程核對來源與安裝模式；每輪工作前偵測到 Git 來源就先安全更新，再重新讀取本輪需要的規範。連結模式更新來源即可，不重新複製；複製模式依 LIN 規範同步副本。同一 repo 同輪僅一次；由不同執行端接手時核對該端自己的安裝。
3. 本機缺少 LIN 時，使用者已授權從上述獨立 repo 直接安裝 lin-frontend，不重複請示，依 [Skill 依賴與安裝](skill-dependencies.md) 核對當前工具與來源；不讀本 repo 的歷史副本冒充最新版。沒有本機操作能力時明列限制，不能宣稱已安裝。更新失敗明列未確認最新，已有規範可做的部分繼續，平台契約缺口不猜。
4. 本方案的方向／母版／角色／動態範圍／RWD 與確認節點仍有效。LIN 只提供共用工程規範，不取代方案流程。發現真正衝突時列來源及影響，不自行擴大授權。
5. 交付仍分開列靜態驗證、客戶確認、工程師接入、後台儲存與發布驗證。
