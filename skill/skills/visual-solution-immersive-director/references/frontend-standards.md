# 共用切版規範｜獨立 LIN

共用規範唯一來源：[world-yingcen/lin-skill](https://github.com/world-yingcen/lin-skill)。本方案不再維護共用條文副本。

1. 依當前工具的 Skill 清單定位已安裝的 lin-frontend，完整讀取其 SKILL.md。
2. 按 LIN「每次使用」流程核對來源、更新、重新讀取，再按本輪工作讀取 references。同輪僅更新一次；由不同執行端接手時核對該端自己的安裝。
3. 缺少 LIN 時，告知需要安裝獨立 repo 的完整 Skill，取得授權再安裝；不讀取本 repo 的歷史副本冒充最新版。更新失敗明列未確認最新，已有規範可做的部分繼續，平台契約缺口不猜。
4. 本方案的方向／母版／角色／動態範圍／RWD 與確認節點仍有效。LIN 只提供共用工程規範，不取代方案流程。發現真正衝突時列來源及影響，不自行擴大授權。
5. 交付仍分開列靜態驗證、客戶確認、工程師接入、後台儲存與發布驗證。
