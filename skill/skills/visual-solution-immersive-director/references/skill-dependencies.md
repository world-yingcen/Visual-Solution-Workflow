# 本機缺少相關 Skill：直接安裝

使用者於 2026-10-14 明確授權：**發現本機沒有本輪需要的 Skill，就直接幫忙安裝，不再逐次詢問。** 只安裝本輪相關 Skill 及其確實必要的依賴，不預先裝所有可能用到的工具。

## 核對與執行

1. 先從當前執行端的 Skill 清單及安裝紀錄確認缺少什麼；Codex、Claude Code 各核對自己的位置。已存在且可用就直接讀取，不重裝；不能把另一工具已安裝當成本工具已具備。
2. 使用本案已確認的來源與其官方安裝器。Lin-EVO 來源為 `world-yingcen/lin-skill`，只需 Lin-EVO 時指定 `--skill Lin-EVO`，不順便安裝 Miffy-EVO。GSAP 與 Eagle 可用本 workflow Git 來源隨附的已核對版本及套件安裝方式；其他 Skill 優先使用已指定來源或當前工具官方／可信安裝器，不猜 repo 或執行來路不明腳本。
3. 缺來源 checkout 時，可取得已確認的 Skill repo 至固定本機工具庫位置，再按來源規範安裝／連結；不放客戶案件或雲端同步資料夾。沿用現有位置與安裝方式，不改全域設定、不遷移其他 Skill。來源套件必須一起提供的支援檔案可隨附，不因此安裝對應應用程式。
4. 核對同名 Skill、來源及本機修改。不同來源、不受管理或有本機修改時保留現況，提出具體衝突；不刪除、強制覆蓋、reset 或 stash。沒有可信來源、缺帳號／權限或安裝能力時列缺口，繼續不受影響的工作；需要使用者操作登入或處理實際權限時才交回，不索取密碼。
5. 安裝後檢查完整檔案、來源／連結、入口與所需參考，立即重讀新規則。需要工具重新載入才能出現在清單時如實說明，不能只因安裝指令成功就宣稱本輪已載入。

## 授權範圍

設計方向必須通過 [參考關卡（二擇一）](reference-research.md#設計方向前的參考關卡二擇一)。已有足夠且已實際分析的使用者參考時，不強制安裝或連接 Eagle；沒有可用參考時才必須透過 Eagle 查找。Eagle Skill 只是操作規則，採此路徑須有 MCP／API 或已授權的螢幕控制能實際搜尋與查看指定資料庫。缺少時先請使用者或維護者完成設定，或請使用者提供可分析參考，不能只完成 Skill 安裝就宣稱已看過參考。

本授權針對 Skill，並不自動涵蓋 Eagle 應用程式、Chrome 擴充功能、Node／Sass／JS 套件、工程師工具庫、API 金鑰、帳號訂閱、系統權限、部署或跨工具派工；這些依既有本案授權與需要處理。EVO 系統 vendor 仍依平台契約，不為缺檔自行補 CDN。

Claude 網頁／App 的上傳 Skill 不等於有本機安裝權限或檔案存取能力。若當次工具沒有本機安裝功能，不能遠端操作使用者的 Skills 目錄；先使用已啟用的 Skill。缺少但無法安裝時，提供確切 Skill 名稱與上傳／啟用方式；使用者另外上傳 Lin-EVO、GSAP 的分工維持，不把依賴再塞回 workflow ZIP。
