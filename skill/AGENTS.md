# 整體視覺方案｜角色與工作規則

本專案用於維護整體視覺方案 Skills。修改流程文件不自動啟動客戶案件、不安裝工具、不推送或部署。

## 主入口與流程邊界

整體視覺案件的「開始／繼續／下一步」統一使用 [整體視覺主 Skill](skills/visual-solution-immersive-director/SKILL.md)，由同一任務整合設計、素材、實作與自查。不要預設啟動五角色流程或建立多代理。

主 Skill 預設先完成並驗收 2560×1280 桌機版；本階段不做 RWD。Tablet／Mobile 只有在使用者後續明確要求時才另開範圍，不能因舊流程文件而提早加入。

本案的品牌、內容架構、參考使用方式與確認紀錄是依據。高效方案的母版選擇、流程、產圖管道及驗收結論不能跨案繼承。資料庫保留的高效歷史案例僅供查閱，不構成製作規則。

## 現行入口

設計、實作與自查是同一主 Skill 的工作責任，不是不同角色 Skill。按需讀取主 Skill 的 references。

Eagle 工具另用於資源庫操作，不是製作角色。

## 共通原則

- 使用繁體中文與台灣用語，視覺與互動必須有品牌及使用目的。
- PRD 管內容／功能／範圍；共同 Brief 與確認過的參考使用方式管設計。參考網站不能自行覆蓋品牌或需求。
- 指定忠實重建就忠實重建；指定特徵轉譯只保留約定特徵；原創方向不硬套母版。只說「參考」時先具體整理保留與可改部分，再釐清會影響結果的歧義。
- 設計交接必須包含 2560×1280 構圖、圖片與互動起始／過程／結束狀態，以及減少動態方案；不只交風格形容詞。手機方案僅在 RWD 已明確納入範圍時要求。
- 沿用既有工程、版本與元件。系統頁遵守本案平台契約，不把系統模板限制強加於所有創意區塊。
- 實作自查、人員確認分開記錄；只有實際執行獨立複核才記該狀態，未實看、未實測不能宣稱通過。
- 案件製作全程使用 Claude App，依階段讀取整體視覺、Lin-EVO 與 Miffy-EVO，不另問工具分工或自動派給 Codex。核心片段確認後才進入 Lin-EVO 的完整首頁切版。產圖由 Claude 提供 Prompt，使用者手動貼到 ChatGPT 產圖並下載至指定的 `image/` 資料夾；圖片轉檔與壓縮也由使用者處理。檔案存取、預覽與後台操作以實際工具能力及授權為準，不能把本機路徑當成已讀取證據。
- Skill 名稱與資料夾名稱一致。此套件使用 `visual-solution-*`，不得回寫既有高效套件。

完整狀態見 [轉版狀態](轉版狀態.md)。
